LOCAL ACCESS

设置

访问策略保存在本机，执行客户端不能修改这些设置。

机器保护清单

受保护机器可查看控制端元数据，执行、文件访问、已有绑定与恢复均受保护策略约束。不会终止已接受的请求。

文件与恢复策略

仅限制文件 API 的规范绝对路径；不是命令或符号链接的安全沙箱。命令使用 Guest 自身权限。

开启策略本身不会恢复机器；每次恢复仍需显式允许，可能增加运行时间。普通查询不主动 resume。

客户端接入

运行命令 igw token execution 获取执行凭据，交给受信客户端。客户端无需上游 API Key，也不能修改账号或保护清单。

凭据通过隐藏输入或环境变量提供，不写入 URL。执行客户端具有允许目标上的 Guest 执行能力；不适用于不受信客户端。
